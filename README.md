# Face Verification System

**A Computer Vision Project for Facial Feature Extraction, Similarity-Based Matching, and Identity Verification**

## Overview

This project implements a face verification pipeline using InsightFace and ArcFace-based facial embeddings. It explores how facial representations can be extracted from images, compared in an embedding space, and used to determine whether two face samples are likely to belong to the same person.

The system combines face detection, embedding extraction, L2 normalization, cosine-similarity comparison, and threshold-based decision-making. A webcam interface is also used to explore real-time face matching and identity recognition.

The project focuses on understanding the complete workflow, evaluating matching behavior, and examining the challenges of reliable face verification.

## Key Features

- Face detection using InsightFace
- Facial embedding extraction using a pretrained ArcFace-based model
- 512-dimensional feature representations
- L2 normalization for consistent similarity comparison
- Cosine-similarity-based matching
- Threshold-based verification decisions
- Reference embedding database with identity labels and image paths
- OpenCV webcam integration
- Preliminary evaluation of identification performance

## System Architecture

The pipeline is organized into the following stages:

1. **Image Input:** Load face images from the reference dataset.
2. **Face Detection:** Detect facial regions using InsightFace.
3. **Embedding Extraction:** Generate a 512-dimensional feature vector for each detected face.
4. **Feature Normalization:** Apply L2 normalization to the extracted embeddings.
5. **Reference Database Construction:** Store embeddings alongside identity labels and corresponding image paths.
6. **Similarity Computation:** Compare a query embedding against reference embeddings using cosine similarity.
7. **Decision Making:** Apply a configurable threshold to determine whether a match should be accepted or rejected.
8. **Visual Inference:** Use OpenCV to display webcam results and matching information.

## Technical Approach

### Facial Embeddings

Instead of comparing raw pixel values, the system represents each detected face as a numerical embedding generated by a pretrained face-recognition model.

These embeddings provide a feature space in which faces with similar learned characteristics can be compared using vector similarity.

### L2 Normalization

Each embedding is normalized to unit length before comparison. This makes the dot product between normalized embeddings equivalent to cosine similarity, subject to numerical precision.

### Similarity-Based Matching

For normalized embeddings \(x\) and \(y\), cosine similarity is calculated as:

\[
s(x,y)=\frac{x\cdot y}{\|x\|_2\|y\|_2}
\]

A higher similarity score indicates greater alignment between the two feature vectors. However, similarity alone does not guarantee that two images belong to the same person.

### Threshold-Based Decision

The system uses a configurable threshold to distinguish accepted matches from rejected matches.

The threshold must be calibrated on representative validation data. A lower threshold may increase false acceptances, while a higher threshold may increase false rejections.

## Preliminary Evaluation

In an initial closed-set identification experiment, one image per identity was used as a query while the remaining images were used as reference samples.

| Metric | Result |
|---|---:|
| Correct identifications | 475 / 485 |
| Top-1 identification accuracy | 97.94% |

These results describe the initial identification experiment only. They should not be interpreted as face-verification accuracy, open-set recognition performance, or guaranteed real-time webcam accuracy.

A separate verification evaluation requires genuine and impostor image pairs, with metrics such as False Acceptance Rate (FAR), False Rejection Rate (FRR), ROC-AUC, and Equal Error Rate (EER).

## Installation

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\activate
```

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

The pretrained model may require a separate download on first use.

## Usage

1. Configure the local dataset path.
2. Run the database-building workflow to extract and save reference embeddings.
3. Load the generated embedding database.
4. Run the webcam workflow to perform face matching.
5. Adjust and validate the decision threshold using a dedicated validation set.

The dataset, generated embeddings, and local model files are not included in the repository by default.

## Limitations

- Performance depends on image quality, pose, lighting, occlusion, and face-detection reliability.
- The initial evaluation does not establish generalization to unseen identities.
- Threshold selection requires independent validation.
- Similarity-based matching does not provide liveness detection or spoofing protection.
- The current results are preliminary and are not a substitute for production-level biometric evaluation.
